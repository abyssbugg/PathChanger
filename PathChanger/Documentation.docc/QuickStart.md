# Quick Start

Get started with PathChanger in minutes.

## Overview

This guide walks you through your first location simulation session.

## Connecting a Device

1. **Connect via USB**: Plug your iOS device into your Mac
2. **Trust Computer**: Accept the trust dialog on your device
3. **Launch PathChanger**: Open the application
4. **Select Device**: Click on your device in the left sidebar

## Teleport Mode

Teleport Mode instantly sets your location to any coordinate.

### Using the Map

1. Use the search bar to find a location
2. Click **Set Location** to teleport
3. Your device's GPS will update to the new location

### Using Coordinates

1. Enter latitude and longitude manually
2. Click **Set Location** to apply
3. Coordinates support 6 decimal places for precision

### Preset Locations

Quick-access preset locations are available:
- **Times Square, NY**: 40.7580° N, 73.9855° W
- **Eiffel Tower, Paris**: 48.8584° N, 2.2945° E
- **Tokyo Tower**: 35.6586° N, 139.7454° E

## Route Mode

Route Mode plays back GPX routes at configurable speeds.

### Loading a Route

1. Click **Import GPX** in the sidebar
2. Select a GPX file from your computer
3. The route will display on the map

### Playing a Route

1. Select a speed (Walking, Running, Cycling, Driving)
2. Click **Play** to start playback
3. Use **Pause** to temporarily stop
4. Enable **Loop** for continuous playback

### Speed Settings

| Mode | Speed |
|------|-------|
| Walking | 5 km/h |
| Running | 12 km/h |
| Cycling | 25 km/h |
| Driving | 60 km/h |

## Joystick Mode

Joystick Mode provides real-time movement control.

### Keyboard Controls

- **W / ↑**: Move forward
- **S / ↓**: Move backward
- **A / ←**: Turn left
- **D / →**: Turn right
- **Shift**: Speed boost

### On-Screen Joystick

1. Click and drag the joystick control
2. Distance from center controls speed
3. Direction controls movement direction

## Clearing Location

To reset to your device's real GPS:

1. Click **Clear Location** in the toolbar
2. Confirm the action
3. Your device will return to its actual location

## Tips

- Use **Performance Mode** for smoother joystick control
- Save frequently-used locations as favorites
- Check **Device Status** for connection health
- Use keyboard shortcuts for faster workflow (Cmd+L for location)
